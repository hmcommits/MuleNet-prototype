# MuleNet — AI-Powered Money Mule Detection Dashboard

> **Prototype** · Next.js 16 · Tailwind CSS v4 · Framer Motion · Lucide React

MuleNet is an autonomous **Heterogeneous Graph Neural Network (H-GNN)** compliance engine that treats money laundering like a virus — running "contact tracing" on illicit funds in real time.

---

## 🚀 What It Does

| Feature | Description |
|---|---|
| **H-GNN Graph Visualizer** | Interactive SVG canvas showing a live multi-entity topology — Bank Accounts (circles), Devices (squares), IP Subnets (hexagons) — with neon glow effects |
| **Simulate Attack** | One-click scatter-gather money mule simulation: Victim → 4 Mules → Mochatrade, with animated red edges and Ghost Farm device linkage |
| **Threat Telemetry** | Zero-Dwell Velocity Meter that spikes on attack detection, plus click-to-inspect node inspector |
| **GNNExplainer Dossier** | AI-isolated minimal subgraph evidence table + "Generate Evidentiary Dossier (Sec 102 CrPC)" — produces a PDF-style law enforcement report modal |
